# Python-First-Projects
Портфолио базовых проектов на Python от byKollins. Внутри: консольная утилита «Домашняя бухгалтерия» с сохранением данных и две пошаговые RPG-игры с разной боевой механикой.


Мои первые проекты на Python 🚀

Добро пожаловать! Здесь собраны мои первые полноценные программы, написанные в процессе изучения базового синтаксиса Python. 

📁 Что внутри репозитория:

1. 💳 Wallet.py — Умная домашняя бухгалтерия (Софт)
Консольная утилита для ведения учета личных финансов.
Фичи: Меню в столбик, добавление покупок, красивый вывод расходов списком, автоматический подсчет общей суммы и сохранение/загрузка данных через текстовый файл.

2. 🛡️ Mini-game.py — Текстовая RPG «Сударь и Подорожник» (Игра №1)
Первая версия пошаговой игры в благородном стиле.
Фичи: Система проверки здоровья, интерактивное использование подорожника из сумки для лечения и система наград (медаль за живучесть).

3. ⚔️ Mini-game2.py — Пошаговая RPG «Охота на Гоблина» (Игра №2)
Продвинутый игровой движок с элементом непредсказуемости.
Фичи: Случайный ответный урон противника (модуль `random`), пошаговый файт, сбор трофеев и автосохранение инвентаря на жесткий диск перед выходом.
