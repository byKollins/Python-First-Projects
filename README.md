Python-First-Projects

Портфолио базовых проектов на Python от byKollins. Внутри: консольная утилита «Домашняя бухгалтерия», текстовые RPG-игры, классические мини-игры и список дел с сохранением данных.

Мои первые проекты на Python 🚀

Добро пожаловать! Здесь собраны мои первые полноценные программы, написанные в процессе изучения Python.

📁 Что внутри репозитория
1. 💳 Wallet.py — Умная домашняя бухгалтерия

Консольная утилита для ведения учёта личных финансов.

Фичи: меню в столбик, добавление покупок, красивый вывод расходов списком, автоматический подсчёт общей суммы и сохранение/загрузка данных через текстовый файл.

2. 🛡️ Mini-game.py — Текстовая RPG «Сударь и Подорожник»

Первая версия пошаговой игры в благородном стиле.

Фичи: система проверки здоровья, интерактивное использование подорожника из сумки для лечения и система наград (медаль за живучесть).

3. ⚔️ Mini-game2.py — Пошаговая RPG «Охота на Гоблина»

Продвинутый игровой движок с элементом непредсказуемости.

Фичи: случайный ответный урон противника (модуль random), пошаговый файт, сбор трофеев и автосохранение инвентаря на жёсткий диск перед выходом.

4. 🎯 Guess the number.py — «Угадай число»

Компьютер загадывает число от 1 до 100, а игрок пытается его угадать.

Фичи: подсказки «больше / меньше», ограничение в 15 попыток, защита от неверного ввода (try/except), запоминание всех догадок и защита от повторов, возможность сыграть ещё раз.

5. ✊ Rock, Paper, Scissors.py — «Камень, ножницы, бумага»

Игра против компьютера.

Фичи: случайный выбор компьютера (random.choice), правила игры хранятся в словаре, подсчёт побед, поражений и ничьих, выход по команде «Выход» с итоговым счётом.

6. ✅ To-do list.py — Список дел

Консольный менеджер задач, который помнит всё между запусками.

Фичи: добавление, удаление и отметка задач выполненными, сохранение и загрузка данных в формате JSON, проверка пользовательского ввода.
